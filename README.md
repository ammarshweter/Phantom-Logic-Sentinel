## 🚀 Overview
**Phantom Logic Sentinel (PLS)** is an advanced, enterprise-grade cybersecurity framework engineered to protect Large Language Model (LLM) applications and critical systems against sophisticated **Indirect Prompt Injections**, **Data Exfiltration**, and unauthorized semantic tampering. 

Unlike traditional Web Application Firewalls (WAFs) that rely solely on passive blocking, PLS introduces **Autonomous Honey-Logic** and **Dynamic Context Poisoning** to actively deceive, isolate, and neutralize malicious adversaries in real-time.

---

## ✨ Key Features

* **🧬 Dynamic Context Poisoning:** Automatically mutates secure vault states and data streams into convincing decoy payloads upon detecting prompt injection attempts, feeding attackers false intelligence.
* **🤖 Semantic Intent Analysis:** Inspects incoming payloads using behavioral signatures and neural risk-scoring algorithms to detect subtle evasion patterns.
* **📊 Real-Time SOC Dashboard:** Built entirely with Python and Streamlit, providing live threat analytics, real-time risk scoring, and interactive attack simulation loops.
* **🎯 Autonomous Deception Traps (Honey-Logic):** Deploys automated honey-tokens that instantly trigger adversary isolation and track threat vectors.
